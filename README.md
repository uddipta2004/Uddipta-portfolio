# Uddipta Bhattacharya — Personal Portfolio

A handcrafted, premium personal portfolio website designed for **Uddipta Bhattacharya** (BCA Graduate, Nalbari College / Gauhati University, Class of 2026).

Built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## 🧭 Live Preview & Development

The development server is actively running at:
- **Local:** [http://localhost:3000/](http://localhost:3000/)
- **Network:** Available on local subnet

### To start development server manually:
```bash
npm run dev
```

### To build for production:
```bash
npm run build
```

### To preview production build:
```bash
npm run preview
```

## 🎨 Visual Identity & Design Principles

- **Palette:** Deep Navy (`#070c18`, `#0b1325`), crisp Off-White text (`#f8fafc`, `#cbd5e1`), and subtle Cyan accents (`#06b6d4`).
- **Typography:** Display headings with `Outfit`, body text with `Plus Jakarta Sans`, and technical badges with `JetBrains Mono`.
- **Anti-AI Design Language:**
  - Distinct architectural layouts with generous whitespace and intentional asymmetry.
  - Zero fake skill percentage bars or artificial proficiency meters.
  - Authentic, verified details directly reflecting academic achievements, certifications, and project implementations.
  - Handcrafted browser mockups illustrating real healthcare application flows for VaxiCare and Niramoy.
  - Deep-dive Architecture Modal allowing recruiters to inspect relational database schemas and data flows.
